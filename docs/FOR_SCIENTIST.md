# ANSYS REPORT: что готово (для проверки научным руководителем)

Автоматическая сборка технического отчёта по ГОСТ Р 58622-2019 для вертикального стального резервуара (РВС): заказчик присылает замеры нивелировки,
сайт строит модель, показывает нагрузки, Ansys на ПК считает, возвращается отчёт Word и Excel.

## Как это устроено
1. **Сайт** (Python, FastAPI): студия из 7 шагов, страница расчёта, кабинет. Ansys на сервере НЕ нужен.
2. **Помощник** на ПК с Ansys (Mechanical 2026 R1): по ссылке с сайта скачивает модель, строит её в Workbench/Mechanical, решает, выгружает результаты, собирает отчёт и отправляет на сайт. Окон консоли у заказчика нет.
3. **Отчёт** Word (структура и разделы как в эталонных отчётах) + Excel.

## Что уже работает
- Загрузка замеров: проект «РВС Геометрия» (.json) или нивелировка (.xlsx, выбирается лист «пустой»), либо таблица из Excel; обязательные толщины поясов вводятся вручную или распознаются из документа (паспорт, толщинометрия, отчёт: таблицы и фразы «с первого по второй – 16,0 мм»).
- Проверка допусков (H/200, H/200+30), восстановленная стенка в 3D, вмятины по локальным измерениям.
- Конструкция: днище и окрайка, крыша (каркас, кольца, настил), патрубки, каталог профилей балок (ГОСТ 8239, 8240, 8509 и по габаритам), ветровые кольца жёсткости.
- Выгрузка STEP (стенка по поясам, целая модель).
- **Нагрузки на модели**: гидростатика, избыточное давление, вакуум, снег, ветер, вес по расчётным случаям отчёта; показ давления на стенку, крышу и днище прямо на сайте (обновляется при вводе, формула та же, что в скрипте для Ansys).
- Ansys: сборка модели (оболочки, толщины по поясам, сетка 200 мм, сгущение 100 мм у вмятин, балки BEAM188), решение (5 статических случаев + устойчивость), результаты по поясам, картинки, отчёт.
- Отчёт: прочность по поясам (мембранные, фибровые, эквивалентные), допустимая высота налива, устойчивость (Ansys), аналитическая проверка устойчивости по ГОСТ 31385 (раздел 6.2).
- Время сквозного прогона РВС-10000: около 8–12 минут (решатель считает секунды, остальное Workbench).
- Тесты: 70+ автоматических (расчёт нагрузок сверен с Excel), проверка в браузере.

## Сверка с эталонным отчётом (Т-001, РВС-9985)
Мембранные напряжения по поясам при наливе 17,2 м: пояса 1–11 совпадают с эталоном в пределах 4–12 % (наши ниже), допустимый налив тот же (не менее 17,2 м).
Расхождения, которые решаем (см. ниже): пояс 12 (стык «стенка–крыша»), запас устойчивости.

## Вопросы, на которые нужны ответы
1. **Критерий прочности по мембранным напряжениям:** в эталоне σм ≤ [σ] = σ0,2/1,5; у нас сейчас σм ≤ 1,5[σ]. Какой правильный?
2. **Устойчивость:** в эталоне нелинейная постановка, ветер-возмущение в двух направлениях, k = 10…15; у нас линейный расчёт собственных значений (k ≈ 1,4–1,8, это запас настила крыши, не стенки). Нужны: распределение давления ветра по окружности cp(θ), величина и направления возмущения, требуемый k.
3. **Толщины:** правило «минимальная толщина по поясу для прочности, максимальная для устойчивости»: брать из толщинометрии (мин./макс. по поясу)?
4. **Коэффициент надёжности на гидростатику** (в эталоне, видимо, 1,05): применяется?
5. **Стык «стенка–крыша»:** как в эталонном расчёте передаются нагрузки от крыши на стенку (в нашей модели пик на 12 поясе 220 МПа против 17 в эталоне)?

## Как запустить сайт для проверки
См. раздел «Запуск» ниже и docs/DEPLOY_SERVER.md (боевой сервер: nginx, HTTPS, PostgreSQL). Скриншоты: docs/screens/.

### Быстрый запуск (Windows или Linux, Python 3.12/3.13)
```
git clone https://github.com/daniilmityashkin-cell/Ansys-report.git
cd Ansys-report
git checkout claude/ansys-report-automation-8asxtm
python -m venv .venv && .venv\Scripts\activate        (Linux: source .venv/bin/activate)
pip install -r requirements-server.txt
python -m server                                       (сайт на http://127.0.0.1:8000)
```
Оплата в режиме разработки тестовая (деньги не списываются). Для расчёта нужен ПК с Ansys и помощник (`python -m ansys_report agent --install`); для просмотра студии, нагрузок и отчётов Ansys не нужен.

## Что НЕ готово
- Нелинейный расчёт устойчивости по эталонной схеме (ждём данные).
- Установщик помощника для заказчиков (.exe), боевой сервер с HTTPS и настоящей оплатой, договор и политика.
- Проверка на других версиях Ansys и на чужих ПК.
- Профили серий Б/Ш/К в каталоге (задаются габаритами).
