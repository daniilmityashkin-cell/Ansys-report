Помощник для Ansys

Помощник работает на вашем компьютере, где установлен Ansys: по кнопке «Собрать отчёт в Ansys» на странице расчёта он скачивает модель, запускает Ansys, считает и отправляет готовый технический отчёт на сайт.

Установка (один раз)

  1. Установите Python 3.12 и пакеты программы ANSYS REPORT (или готовый установщик AnsysReport_Setup.exe).
  2. Откройте PowerShell в папке программы и выполните: python -m ansys_report agent --install
  3. Вернитесь на страницу расчёта и нажмите «Собрать отчёт в Ansys». Браузер спросит разрешение открыть помощника: подтвердите и отметьте «всегда разрешать».

Помощник скачивает только пакет вашего расчёта и отправляет обратно только готовые файлы отчёта.
