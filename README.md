# ansys-report — автоматизация отчётов по расчёту РВС в Ansys

Из одного файла исходных данных получаем **Word-отчёт** (по образцу `ТО_Прочностной_расчет_…docx`)
и **Excel «Нивелировка»** (по образцу `Нивелировка Т001-Т004.xlsx`) вместе с текстовыми файлами точек для импорта в Ansys.

## Запуск (Windows)
```
pip install -r requirements.txt
python -m ansys_report all examples\T001\project.yaml -o out
```
Команды: `excel`, `word`, `all`. Результат в папке `out`:
* `Нивелировка Т-001.xlsx` — листы «полный», «пустой», «Проверка» (допуск 1/200); всё живыми формулами, синим — вводимые данные;
* `points_Т-001_full.txt`, `points_Т-001_empty.txt` — точки Z/X/Y (`3d=true`, `Fit=false`);
* `ТО_ТО-019-26_Т-001.docx` — отчёт. Оглавление обновляется при открытии в Word (согласиться на обновление полей).

## Как сделать отчёт для нового резервуара
1. Скопировать `examples/T001` → `examples/T002`.
2. `project.yaml` — геометрия, толщины, материал, нагрузки, данные отчёта.
3. `survey_full.csv`, `survey_empty.csv` — отклонения стенки, мм (строки — точки, столбцы `belt1…beltN`).
4. `results_full.csv` — максимумы по поясам из Ansys (`belt,fiber,equivalent,membrane`, МПа); коэффициенты устойчивости — в `project.yaml`.
5. Картинки из Ansys — в `images/` под именами `fig01_general.png`, `fig02_mesh_wall_bottom.png`, … (список в `word_gen.py`,
   сообщение «Нет N рисунков» при запуске). Отсутствующие заменяются красной заглушкой.

Всё автоматически считается и подставляется: R=σт·γc/(γm·γn), [σ]=σ0,2/1,5, E2, нагрузка от крыши, допуски 1/200,
вердикты «Выполнен / Не выполнен» по каждому поясу, выводы. Проверено на данных образца: R=206,35/235,83/353,74 МПа,
E2=743,7 МПа, F=734643,9 Н, 1152 координаты точек совпадают с образцом.

## Что дальше (идеи)
* Автовыгрузка максимумов по поясам и картинок прямо из Ansys Mechanical (скрипт ACT/PyMechanical) → `results_full.csv`, `images/`.
* Другие типы объектов (опоры АЭС): отдельный шаблон отчёта и набор критериев, ядро загрузки/расчёта/вывода переиспользуется.
* Простой GUI для коллеги (формы вместо YAML).
* Шаблон Word: `python tools/make_template.py <образец.docx>` пересоздаёт `templates/base.docx` из любого отчёта (стили, колонтитулы).

## Допущения
* Проверка «Проверка»: отклонение пояса k от вертикали = max |dk − d1| по точкам относительно 1-го пояса; допуск k·h/200 — трактовка образца, уточнить у научрука.
* Формулы γc=0,7/0,8/1,2, γm=γn=1,05 восстановлены из образца.
