О программеAnsys Report · автоматизация технических отчётов по расчётам в Ansys

Программа берёт геометрию, нагрузки, напряжения по поясам, коэффициенты устойчивости и рисунки прямо из вашего проекта Ansys и собирает технический отчёт Word, нивелировку Excel и файлы точек.

Для работы нужен установленный Ansys Mechanical с действующей лицензией. Проект Ansys программа не изменяет. Подробности — в руководстве пользователя (docs/USER_GUIDE.md).
