# CRM ANSYS REPORT

Отдельная система (пакет `crm/`, свой сервер и своя база), связана с сайтом по API. Вход для администратора и менеджеров, удобно с телефона.

## Что умеет
- **Заявки и события с сайта в одном месте**: регистрация, заказ (замеры), нагрузки, данные отчёта, «Собрать отчёт», оплата (сумма, провайдер, способ),
  готовый отчёт, ошибка расчёта, скачивание, этапы помощника Ansys; форма «Оставить заявку» на главной. Источник лида: utm-метки, сайт перехода, страница входа.
- **Сделки по воронке** (канбан): Новый лид → Связались → Замеры загружены → Готовит расчёт → Ожидает оплаты → Оплачено → Отчёт выдан / Проигран.
  Двигаются сами по действиям клиента; вручную - в любой этап. Повторный заказ после выданного отчёта - новая сделка.
- **Задачи**: мои / все / выполненные, сроки, просрочка (красный счётчик), срочные.
- **Автосценарии** (включаются в «Настройках»). По умолчанию (решение владельца) включены только задачи «не оплатил за 24 ч» и «ошибка расчёта»;
  задача «связаться за 15 минут», письма клиентам и Telegram выключены - всё видно в самой CRM. Остальное: новый лид → задача «связаться за 15 минут», письмо «спасибо», уведомление в Telegram;
  «нажал оплату, но не оплатил 24 ч» → задача «дожать» (закрывается сама после оплаты); оплата → Telegram; ошибка расчёта → срочная задача + Telegram;
  отчёт готов → письмо клиенту. Звонок/письмо клиенту закрывает задачу «связаться» и двигает сделку в «Связались».
- **Карточка клиента**: позвонить / WhatsApp / письмо в одно касание, вся история (сайт, звонки, письма, заметки, этапы, оплаты), сделки, задачи,
  теги, регион, ответственный, следующий шаг.
- **Сегменты и рассылки**: фильтры (новые, оплатившие, повторные, не оплатившие, этап, источник, регион, тег, нет активности N дней),
  сохранение сегмента, выгрузка в Excel (CSV), письмо всей выборке.
- **Аналитика**: выручка, средний чек, лиды, конверсия визит → лид → оплата, по этапам, по источникам и страницам входа, дни до оплаты,
  выигранные/проигранные, работа менеджеров, график по дням.

## Связь с сайтом
- Сайт пишет события в свою таблицу `events` и отправляет их в CRM пачками каждые 10 с (`server/crm_sync.py`). CRM выключена - события ждут;
  повторная доставка безопасна.
- Сайт: `ASR_CRM_URL` (адрес CRM), `ASR_CRM_TOKEN` (= токен API CRM).
- Любые другие формы/виджеты/телефония/1С: `POST /api/v1/leads` (JSON или форма: name, phone, email, company, message, form, page, utm_*),
  `POST /api/v1/events`; заголовок `Authorization: Bearer <токен>`.

## Настройка (переменные окружения CRM_)
| Переменная | Что |
|---|---|
| `CRM_DATA_DIR` | папка базы (по умолчанию `crm_data`) |
| `CRM_API_TOKEN` | токен API (пусто - создаётся в `crm_data/api_token.txt`) |
| `CRM_ADMIN_EMAIL`, `CRM_ADMIN_PASSWORD` | первый администратор (или `python -m crm adduser почта пароль admin`) |
| `CRM_SITE_URL`, `CRM_PUBLIC_URL` | адреса сайта и CRM (для ссылок в письмах и Telegram) |
| `CRM_TG_TOKEN`, `CRM_TG_CHAT` | Telegram-бот (@BotFather) и чат, куда слать уведомления |
| `CRM_SMTP_HOST`, `CRM_SMTP_PORT`, `CRM_SMTP_USER`, `CRM_SMTP_PASSWORD`, `CRM_MAIL_FROM` | почта для писем клиентам |
| `CRM_LEAD_CALL_MIN` (15), `CRM_UNPAID_HOURS` (24) | сроки автозадач |
| `CRM_HOST`, `CRM_PORT` (8100) | адрес сервера |

## Запуск на своём ПК
`start_site_crm.bat` - сайт (8000) и CRM (8100) вместе; при первом запуске спросит почту и пароль администратора CRM.

## На сервере
Два сервиса (systemd): `uvicorn server.wsgi:app --port 8000` и `uvicorn crm.wsgi:app --port 8100`, за nginx (например, `site.ru` и `crm.site.ru`),
`CRM_HTTPS_ONLY=1`. Базы - PostgreSQL через `ASR_DB_URL` и `CRM_DB_URL` (или SQLite на диске сервера).
