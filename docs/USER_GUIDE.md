# Руководство пользователя

## Что делает программа
Из проекта Ansys Mechanical (2026 R1) автоматически собирает технический отчёт Word и нивелировку Excel.
Из Ansys берутся: геометрия и толщины, сетка, нагрузки, напряжения по поясам, коэффициенты устойчивости,
рисунки результатов, нивелировка «пустого» резервуара. Вручную вводятся только сведения, которых нет в Ansys:
номер отчёта, исполнитель, объект.

## Порядок работы
1. В Ansys выполните расчёты (прочность, устойчивость) и сохраните проект как `.wbpj`
   (File → Save As; не как архив `.wbpz`). Закройте Workbench и Mechanical.
2. Запустите программу (`run_gui.bat`).
3. Выберите файл проекта `.wbpj` и папку для отчёта.
4. Заполните «Сведения для отчёта».
5. Нажмите **«СОБРАТЬ ОТЧЁТ»** и дождитесь сообщения «ГОТОВО» (первый раз 5–20 минут).
6. Кнопка «Открыть папку» открывает папку отчёта. В Word включите вид «Разметка страницы» и обновите поля (оглавление).

## Что получается
В подпапке `Report_<позиция>`: Word-отчёт, Excel «Нивелировка», файлы точек для импорта в Ansys.
Проект Ansys не изменяется.

## Если что-то не получилось
В окне программы строки с `!` описывают проблему. Подробные журналы лежат в `Report_<позиция>/_ansys_data`
(`log.txt`, `log_images.txt`, `wb_status.txt`).
* «Все напряжения равны 0» — расчёт не решён или результаты не прочитаны: решите расчёт в Ansys, сохраните проект.
* «SolveRequired» — расчёт в проекте не решён; включите опцию «Дорешать расчёты» или решите вручную (Solve).
* Нет рисунков — проверьте `log_images.txt`.

## Форма «полного» резервуара по замерам нивелировки (автоматически)
1. После первой сборки в папке отчёта лежит `survey_full_template.csv`: отклонения стенки в мм (строки — точки по окружности, столбцы `belt1…beltN`). В шаблоне записан «пустой» резервуар.
2. Замените значения реальными замерами «полного» резервуара и сохраните файл как CSV.
3. В программе в блоке 3 выберите этот файл и нажмите «Собрать отчёт». Программа сама построит макрос APDL, вставит его в расчёт «полного» резервуара в Ansys, решит его и возьмёт новые результаты.
4. Если в расчёте уже есть ваши Commands (например, макрос вставлен вручную), программа форму не вставляет (чтобы она не удвоилась) и пишет об этом в журнале.
Ручной вариант остался: `python -m ansys_report apdl <project.yaml> -o out` создаёт файл макроса.

## Свойства стали
Плотность, модуль Юнга, коэффициент Пуассона, пределы текучести и прочности берутся из Engineering Data проекта Ansys (материал, назначенный телам-поясам). Марку и стандарт стали, относительное удлинение (в Ansys его нет) и толщины проката укажите в сведениях для отчёта. Если файл Engineering Data не найден, используются запасные значения.

## Допущения
Если в проекте Ansys назначена сталь по умолчанию «Structural Steel» (предел текучести 250 МПа), расчётные сопротивления в отчёте будут посчитаны по ней, а не по 09Г2С: назначьте в Ansys нужную сталь.
Раздел 5.2 («пустой» резервуар) считается по расчёту «Static Structural 2» (с ветром).

## Соответствия с проектом Ansys (блок 4 в окне)
Если ваш проект оформлен иначе, чем пример, поменяйте соответствия (запоминаются):
* **Имя тела-пояса** — регулярное выражение, группа 1 — номер пояса снизу вверх. Пример: `^Belt_(\d+)$`.
* **Вертикальная ось** — X, Y или Z (по направлению силы тяжести в Ansys).
* **Расчёты прочности / устойчивости** — с чего начинаются их имена в дереве Mechanical.
* **Расчёт «полного» / «пустого»** — точные имена; пусто — выбираются автоматически (по словам full/empty, иначе по порядку).
* **Подписи расчётов устойчивости** — `Eigenvalue Buckling=Направление ветра Y; Eigenvalue Buckling 2=Направление ветра Z`.
Результат выбора виден в окне после выгрузки (строка «Соответствия: …»).


## Проверка по замерам (вкладка «Замеры»)

Заказчик передаёт точки замеров стенки (файл проекта «РВС · Геометрия стенки», формат JSON). Программа:

1. сравнивает каждый замер с допусками соответствующего пояса: **H/200** и **H/200 + 30 мм** (H — высота пояса от окрайки днища, по таблицам исходных данных к ГОСТ 31385-2016);
2. восстанавливает гладкую поверхность стенки (периодические и естественные кубические сплайны, локальные вмятины отдельными участками);
3. экспортирует единую оболочку для Ansys в **STEP и IGES** (мм, 1:1), границы участков толщины — общие рёбра; толщины — в `Участки толщины.csv`;
4. собирает Word-отчёт (исходные данные, допуски, оценка точек, рисунки, выводы) и HTML для просмотра с ползунками.

Запуск: вкладка «Замеры» → выбрать файл замеров и папку → «Проверить и собрать». Командная строка: `python -m ansys_report geometry замеры.json -o папка`.
Окно ввода таблиц исходного скрипта: `python -m ansys_report geometry-classic` (нужен tkinter).

Алгоритм построения поверхности — скрипт научного руководителя проекта, используется с его разрешения.

### Критерии прочности (ГОСТ Р 58622-2019, таблица 13)

Для листов стенки критерий — мембранные напряжения σм ≤ 1,5·[σ] (где [σ] = σ0,2 / 1,5) и отсутствие локальной потери устойчивости вмятин.
Фибровые и эквивалентные напряжения (σф ≤ 3[σ], σэ ≤ 3[σ]) нормируются для опорного кольца, рёбер жёсткости и патрубков; для стенки они приводятся справочно.
