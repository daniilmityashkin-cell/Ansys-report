# Расчёт в Ansys на нашем сервере

Заказчик ничего не устанавливает: нажимает «Собрать отчёт» и ждёт на странице заказа (очередь → подготовка модели → модель и сетка → расчёт → готово),
потом скачивает Word/Excel. Ansys работает только на расчётном сервере.

- Сайт (`ASR_SERVER_CALC=1`, по умолчанию): после подготовки модели заказ встаёт в очередь (`agent/status.json`, этап `queued`).
- Расчётный сервер: `python -m ansys_report worker --server <адрес сайта> --token <ASR_WORKER_TOKEN>` - постоянно спрашивает `POST /worker/next`,
  берёт заказ, скачивает пакет, строит модель и считает в Ansys (как прежний помощник), шлёт этапы и загружает отчёт на сайт. Заказы по одному.
- Токен расчётного сервера: `ASR_WORKER_TOKEN` на сайте или файл `server_data/worker_token.txt` (создаётся сам).
- Расчёт завис или сервер перезагрузился (этап не менялся 4 часа) - заказ сам возвращается в очередь.
- Ошибка расчёта: заказчик видит «Расчёт не удался, мы разбираемся», в CRM - событие и срочная задача.
- На время разработки расчётный сервер - ПК владельца: `start_site_crm.bat` запускает сайт, CRM и расчётную службу вместе.
- Старый режим «Ansys у заказчика» (помощник по ссылке ansysreport://) - `ASR_SERVER_CALC=0`.
