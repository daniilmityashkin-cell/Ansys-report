# Руководство пользователя

## Что делает программа
Из проекта Ansys Mechanical (2026 R1) автоматически собирает технический отчёт Word и нивелировку Excel.
Из Ansys берутся: геометрия и толщины, сетка, нагрузки, напряжения по поясам, коэффициенты устойчивости,
рисунки результатов, нивелировка «пустого» резервуара. Вручную вводятся только сведения, которых нет в Ansys:
номер отчёта, исполнитель, объект.

## Порядок работы
1. В Ansys выполните расчёты (прочность, устойчивость) и сохраните проект как `.wbpj`
   (File → Save As; не как архив `.wbpz`). Закройте Workbench и Mechanical.
2. Запустите программу (`run_gui.bat`).
3. Выберите файл проекта `.wbpj` и папку для отчёта.
4. Заполните «Сведения для отчёта».
5. Нажмите **«СОБРАТЬ ОТЧЁТ»** и дождитесь сообщения «ГОТОВО» (первый раз 5–20 минут).
6. Кнопка «Открыть папку» открывает папку отчёта. В Word включите вид «Разметка страницы» и обновите поля (оглавление).

## Что получается
В подпапке `Report_<позиция>`: Word-отчёт, Excel «Нивелировка», файлы точек для импорта в Ansys.
Проект Ansys не изменяется.

## Если что-то не получилось
В окне программы строки с `!` описывают проблему. Подробные журналы лежат в `Report_<позиция>/_ansys_data`
(`log.txt`, `log_images.txt`, `wb_status.txt`).
* «Все напряжения равны 0» — расчёт не решён или результаты не прочитаны: решите расчёт в Ansys, сохраните проект.
* «SolveRequired» — расчёт в проекте не решён; включите опцию «Дорешать расчёты» или решите вручную (Solve).
* Нет рисунков — проверьте `log_images.txt`.

## Форма «полного» резервуара по замерам нивелировки
`python -m ansys_report apdl <project.yaml> -o out` создаёт макрос APDL: вставьте его как Commands в анализ
«Static Structural Full» и решите. Узлы стенки сдвигаются по радиусу на (замер «полного» − замер «пустого»).

## Допущения
Свойства стали (09Г2С) берутся из анкеты (в проекте Ansys по умолчанию «Structural Steel»).
Раздел 5.2 («пустой» резервуар) считается по расчёту «Static Structural 2» (с ветром).

## Соответствия с проектом Ansys (блок 4 в окне)
Если ваш проект оформлен иначе, чем пример, поменяйте соответствия (запоминаются):
* **Имя тела-пояса** — регулярное выражение, группа 1 — номер пояса снизу вверх. Пример: `^Belt_(\d+)$`.
* **Вертикальная ось** — X, Y или Z (по направлению силы тяжести в Ansys).
* **Расчёты прочности / устойчивости** — с чего начинаются их имена в дереве Mechanical.
* **Расчёт «полного» / «пустого»** — точные имена; пусто — выбираются автоматически (по словам full/empty, иначе по порядку).
* **Подписи расчётов устойчивости** — `Eigenvalue Buckling=Направление ветра Y; Eigenvalue Buckling 2=Направление ветра Z`.
Результат выбора виден в окне после выгрузки (строка «Соответствия: …»).
