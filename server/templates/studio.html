01 Измерения: от нулей к фактическим данным

Отклонения стенки, мм: «+» наружу, «−» внутрь. Верхняя строка — углы, °; левый столбец — отметки по высоте, м. Значения можно править в ячейках или вставить блоком из Excel.

Допуск и расчёт ведутся в мм.

02 Отклонения каждой образующей

Профили δr(z) по образующим — общий масштаб. Красные точки — измерения.

03 Локальные вмятины

Измерения по локальной области (мм) и восстановленная поверхность. Из файла проекта вмятины подгружаются сами; недостающие можно задать по размерам.

«Добавить по размерам» строит гладкую вмятину колоколом с заданной глубиной в центре — это оценка, а не измерение; для фактических данных загружайте файл проекта.
