## Структура эталона (что должно быть у нас)
Титул (таблица 1x2, название, «Выполнил») -> разрыв страницы -> 1 Вводная часть (1.1 нормы, 1.2 подрядчик) -> 2 Информация об объекте (габариты, уровень налива,
отклонения от вертикали, ссылки на табл. 1-2, рис. 1; Таблица 1 «Характеристика объекта исследования» 18 строк; Таблица 2 «Толщина элементов» I-XII пояс + днище,
столбцы номинальная/расчётная) -> 2.1 Механические характеристики (Таблица 3: сталь, плотность, E, ν, σв, σт, диапазон толщин; расчётные сопротивления 1-го и 2-12 поясов,
билинейная диаграмма, σвр, σу, Δ, E) -> 2.2 Необходимый состав расчёта (цитаты ГОСТ Р 58622 7.2.1-7.2.7, 10.2, формула [σ]=σт/1,5 (33), рисунки-схемы) ->
разрыв -> 3 Сетка (узлы/элементы/качество; Рис. 2 стенка+днище в разрезе, Рис. 3 стенка+кровля) -> разрыв -> 4 Граничные условия и нагрузки (ФОРМУЛЫ с числами: снег Fсн=rS/2,
крыша F=γf(Mкр+ψ·Mоб)g, Pи=γизб·Pизб, вес изоляции стенки/крыши, закрепление днища; допущения; Рис. 4 Нагрузки, Рис. 5 Гидростатика - картинки из Ansys) -> разрыв ->
5 Прочность: 5.1 налив 17,2 м (рис. 6 σэ, 7 σм, 8 σф, 9 деформации + схема образующих; Таблицы фибровые / эквивалентные / мембранные по поясам: № п/п, элемент, σ, оценка критерия),
5.2 пустой (рис. 10-13) -> разрыв -> 6 Устойчивость (рис. 14-17: k, направление ветра Y/Z, моды 1/2) -> разрыв -> 8 Выводы и рекомендации ->
разрыв -> Приложение 1 (нормы) -> Приложение 2 (термины) -> Приложение 3 (исходные данные: таблицы отклонений 1.1 и 1.2 как картинки, требования к моделированию).
