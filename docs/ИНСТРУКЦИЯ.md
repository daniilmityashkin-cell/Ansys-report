# Автоматизация отчётов по расчёту РВС в Ansys: как пользоваться

## Что делает программа
Из проекта Ansys Mechanical (2026 R1) автоматически собирает технический отчёт Word и нивелировку Excel
по образцу оформления (`ТО_Прочностной_расчет_…docx`, `Нивелировка Т001-Т004.xlsx`).
Из Ansys берётся: геометрия и толщины, сетка, нагрузки, результаты по поясам (напряжения), коэффициенты
устойчивости, картинки результатов, нивелировка «пустого» резервуара. Вручную вводится только анкета
(номер отчёта, исполнитель, объект, свойства стали).

## Порядок работы (первый раз ~30 мин, дальше ~5 мин)
1. **Ansys.** Откройте проект, решите расчёты (прочность, устойчивость).
2. **Выгрузка (Mechanical → Automation → Scripting → «+» → вставить → ▶).** Скрипты в папке `ansys_scripts`:
   - `export_model_data.py` → `model_data.json` (тела, толщины, сетка, нагрузки, радиусы колец);
   - `export_results.py` → `*_belts.csv` (максимумы по поясам), `stability.csv`, картинки результатов;
   - `export_model_images.py` → общий вид, сетка, нагрузки (при необходимости пересните сетку вручную: Display → Show Mesh).
   Файлы появляются в `%TEMP%\\ansys_report_out`.
3. **Проект.** Скопируйте файлы в папку проекта (пример — `examples/T001_model`), картинки в `images`.
   Отредактируйте `project.yaml` (только анкета).
4. **Сборка.** `run_gui.bat` или `python -m ansys_report gui` → «Собрать отчёт».
   Результат: Word, Excel «Нивелировка», файлы точек Z/X/Y.
5. **Форма «полного» резервуара.** `python -m ansys_report apdl <project.yaml> -o out` → вставить файл как
   Commands в анализ «Static Structural Full», решить, выгрузить результаты ещё раз.

## Сценарий демонстрации (10 минут)
1. Показать образцы (Word, Excel) и проект Ansys: «вручную это часы работы».
2. Запустить `export_results.py` в Mechanical (1 минута) — появляются CSV и картинки.
3. Открыть окно программы, нажать «Собрать отчёт» — готов Word и Excel.
4. Показать отчёт: титул, оглавление, таблицы по поясам с вердиктами «Выполнен», рисунки, выводы.
5. Показать, что числа совпадают с образцом (напряжения 173–176 МПа, k = 11,6 и 10,9) и что в образце Excel
   найдена ошибка: в листах Т-002/Т-004 высота замыкающей точки на 1 мм больше (2981 вместо 2980).
6. Для другого резервуара — тот же цикл: меняются только модель Ansys и анкета.
