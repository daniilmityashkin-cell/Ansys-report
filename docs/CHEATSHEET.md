# Шпаргалка к показу научруку (среда, 14.10.2026)

## Что говорить в начале (30 секунд)
«Программа подключается к проекту Ansys Mechanical и одной кнопкой собирает технический отчёт Word,
Excel с нивелировкой и файлы точек. Все данные берутся из Ansys: геометрия, толщины, сетка, материал,
нагрузки, напряжения, запасы устойчивости. Вручную вводится только то, чего в Ansys нет: название,
площадка, исполнитель, замеры отклонений стенки.»

## Порядок показа (5–7 минут)
1. **Установка и запуск.** Ярлык на рабочем столе, откроется окно «Отчёт по расчёту».
2. **Карточка 1.** «Выбрать» → `C:\ansys_project\Tank.wbpj`.
3. **Карточка 2.** Папка для результата.
4. **Карточка 3 (по желанию).** CSV замеров «полного» резервуара.
5. **Карточка 4.** Номер отчёта, позиция (Т-002), название РВС, исполнитель. Остальное можно пустым.
6. **Кнопка «Собрать отчёт».** Показать журнал: Ansys запускается сам, ~2 минуты. За это время рассказать
   про соответствия (какой расчёт «полный», какой «пустой») и материал из Ansys.
7. **Результат.** Открыть Word (режим «Разметка страницы»): титул, объект, материал, сетка, нагрузки,
   таблицы напряжений по поясам, устойчивость, выводы. Затем Excel «Нивелировка» и папку с точками.

## Что обязательно подчеркнуть
- Ничего не выдумывается: цифры в таблицах взяты из расчёта (эквивалентные 173,2 МПа, мембранные 165,4 МПа,
  запас устойчивости k = 10,9).
- Критерии допускаемых напряжений считаются по пределу текучести материала из Ansys.
- Время: вручную такой отчёт собирают часы, здесь около 2 минут.

## Если спросят «А для других объектов?»
«Для резервуаров сценарий отлажен полностью. Для проектов другого типа есть универсальный режим:
он описывает модель, материалы, сетку, расчёты и результаты, а для нового типа объекта (опоры, трубы,
клапаны) программа настраивается на примерах проектов и образцах отчётов. Нужны ваши проекты и образцы.»

## Возможные вопросы и ответы
- **Работает ли на других версиях Ansys?** Проверено на 2026 R1. Скрипты используют стандартный
  интерфейс Mechanical; другие версии проверим на ваших установках.
- **Откуда материал?** Из Engineering Data проекта (Structural Steel: 250 МПа). Чтобы получить цифры как в
  образце (09Г2С), назначить эту сталь в Engineering Data.
- **Откуда форма «полного» резервуара?** Из CSV замеров, программа создаёт макрос формы стенки для Ansys.
  Если замеров нет, считается без отклонений.
- **Что если расчёт не решён?** Включена опция «Решить, если не решён», программа решает сама.
- **Безопасность данных?** Всё локально, на компьютере. Данные никуда не отправляются.
- **Коммерческое использование?** Название «Ansys» из продукта будет убрано (торговая марка), логотип свой.

## Если что-то пошло не так
- Окно не открылось: запустить `python -m ansys_report wizard` из PyCharm (запасной вариант).
- Ansys долго считает: подождать, в журнале идёт счётчик «Workbench работает… N мин».
- Совсем не получилось: показать заранее собранный отчёт (папка `Report_T-002`) и объяснить ход работы.
- За день до показа прогнать всё на этом же компьютере.
