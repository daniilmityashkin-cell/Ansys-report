# Памятка пользователя

**Суть.** Программа читает готовый проект Ansys (геометрия, нагрузки, напряжения по поясам, устойчивость, рисунки) и собирает технический отчёт Word, нивелировку Excel и файлы точек. Вручную вводятся только сведения, которых нет в Ansys: номер отчёта, исполнитель, площадка.

## Подготовка проекта в Ansys
1. Расчёты выполнены (зелёные галочки у Solution). Нерешённые программа решит сама (дольше).
2. Пояса стенки названы `p1…pN` (иначе — блок «Соответствия»).
3. Сохраните проект как `.wbpj` (File → Save As), не как архив `.wbpz`.
4. Закройте Workbench и Mechanical.

## Куда положить и какой путь указывать
* Обычная папка без русских букв и пробелов, например `C:\ansys_project\Tank.wbpj`.
* Рядом лежит папка `Tank_files`: всегда копируйте и храните вместе, не переименовывайте.
* В программе: блок 1, кнопка «Выбрать» → файл `Tank.wbpj` (или вставьте путь: Shift + ПКМ по файлу → «Копировать как путь»).

## Порядок работы
1. Откройте программу (ярлык на рабочем столе).
2. Блок 1: файл проекта. Блок 2: папка для отчёта (по умолчанию Документы\AnsysReport).
3. Блок 3: номер отчёта, позиция (T-001), название резервуара, площадка, исполнитель.
4. Переключатели: «Дорешать расчёты» (включён), «Не запускать Ansys заново» (для повторной сборки без Ansys, за секунды).
5. «Собрать отчёт»: около 2 минут (до 15, если расчёты нужно решать). Не закрывайте программу.
6. «Готово»: кнопки «Открыть Word / Excel / папку».

## Результат (папка `Report_<позиция>`)
`Report_<номер>_<позиция>.docx`, `Leveling_<позиция>.xlsx`, `points_<позиция>_full.txt` и `_empty.txt`, служебная папка `_ansys_data` (нужна для режима «Не запускать заново»).

## В Word
Вид → Разметка страницы; согласитесь на обновление полей (оглавление).

## Если не получилось
* Строки с `!` в журнале описывают проблему («все напряжения равны 0» — расчёт не решён; «SolveRequired» — включите «Дорешать»).
* Журнал программы: Win+R → `%LOCALAPPDATA%\AnsysReport\app.log`. Журналы выгрузки: `Report_<позиция>\_ansys_data\log.txt`.
* Word/Excel открыт при пересборке — закройте файл.

## Другой резервуар
Другой проект в блоке 1, другая позиция в блоке 3 (результат в новой подпапке). Другие имена тел или расчётов — блок «Соответствия».

## Не делайте
Не держите проект открытым в Ansys во время сборки; не разделяйте `.wbpj` и `_files`; не переименовывайте папки внутри `Report_<позиция>`.
