# ansys-report — отчёты по расчёту РВС в Ansys одной кнопкой

Программа берёт данные из проекта Ansys Mechanical (геометрия, толщины, сетка, нагрузки, результаты по поясам,
устойчивость, рисунки) и собирает **Word-отчёт**, **Excel «Нивелировка»** и файлы точек. Вводить вручную нужно только
сведения, которых нет в Ansys (номер отчёта, исполнитель, объект).

## Быстрый старт (Windows)
Требуется установленный Ansys Mechanical (проверено на 2026 R1) с действующей лицензией и Python 3.12+.
```
pip install -r requirements.txt
python -m ansys_report wizard        # или двойной щелчок по run_gui.bat
```
В окне: выбрать проект Ansys (`.wbpj`) → заполнить сведения для отчёта → **«СОБРАТЬ ОТЧЁТ»**.
Программа сама запускает Workbench в фоне, открывает проект, выгружает данные, при необходимости дорешивает
нерешённые расчёты и собирает отчёт в подпапку `Report_<позиция>`:
* `Report_<номер>_<позиция>.docx` — технический отчёт (оглавление обновляется при открытии в Word);
* `Leveling_<позиция>.xlsx` — нивелировка (живые формулы, лист «Проверка» с допуском 1/200);
* `points_<позиция>_full.txt`, `points_<позиция>_empty.txt` — точки для импорта в Ansys.

Проект Ansys не изменяется (дорешивание выполняется без сохранения). Все имена файлов и папок — латиницей.

## Требования к проекту Ansys
* Пояса стенки — отдельные тела (по умолчанию `p1…pN` снизу вверх; другие имена — в блоке «Соответствия»).
* Расчёты: «Static Structural …» (прочность) и «Eigenvalue Buckling …» (устойчивость). Нерешённые решаются автоматически.
* Вертикальная ось задаётся в блоке «Соответствия» (по умолчанию X).

## Режимы запуска
* `python -m ansys_report wizard` — главное окно (Ansys → отчёт), открывается в отдельном окне Edge/Chrome.
* `python -m ansys_report wizard-classic` — прежнее простое окно (запасное).
* `python -m ansys_report gui` — сборка из готовой папки проекта (`project.yaml`), без запуска Ansys.
* `python -m ansys_report all examples/demo/project.yaml -o out` — то же из командной строки (`excel`, `word`, `all`).
* `python -m ansys_report apdl <project.yaml> -o out` — макрос APDL формы «полного» резервуара по замерам нивелировки.

## Состав
* `ansys_report/` — программа (расчёт, генерация Word/Excel, подключение к Ansys, окно).
* `ansys_scripts/` — скрипты выгрузки, исполняемые внутри Mechanical (запускаются автоматически; можно и вручную: Automation → Scripting).
* `examples/demo/` — обезличенный пример выгрузки из реального проекта Ansys.
* `tests/` — автотесты (`python -m pytest`).
* `docs/` — инструкция пользователя.

## Допущения
* Формулы по ГОСТ 31385 / СП 16.13330: R=σт·γc/(γm·γn) с γc=0,7/0,8/1,2, γm=γn=1,05; [σ]=σ0,2/1,5; допуск отклонения пояса k·h/200.
* Свойства стали (09Г2С) берутся из анкеты, так как в проекте Ansys по умолчанию «Structural Steel».

## Установщик для пользователей
`installer\build_installer.bat` собирает `dist\AnsysReport\AnsysReport.exe` (PyInstaller) и, если установлен Inno Setup 6,
`installer\Output\AnsysReport_Setup.exe`. Пользователю Python не нужен. Исправления выпускаются новой сборкой того же скрипта.
