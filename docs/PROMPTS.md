# Готовые промпты для работы с Claude Code

Контекст проекта лежит в `CLAUDE.md` и `docs/HANDOFF.md`; Claude читает их первыми.

## Старт новой сессии
```
Прочитай CLAUDE.md и docs/HANDOFF.md, скажи, что делаем первым. Работай в ветке claude/ansys-report-automation-8asxtm, PR не создавай. Отвечай по-русски, коротко; команды для PowerShell давай готовыми блоками.
```

## Сверка с эталонным отчётом (Т-001)
```
Нивелировка 001-004.xlsx, лист «Т-001 пустой». Толщины 12 поясов: 16 14 13 12 12 12 12 12 11 11 11 11. Нагрузки как в tests/data/reference_T001.json (вода 1000 кг/м3, налив 17,2 м, снег 1,8 кПа, ветер 0,3 кПа, местность A, радиус сферы крыши 34,2 м, сталь 09Г2С σу 325 МПа). Сделай сквозной прогон tools/e2e_local.py, в tools/diag/compare_T001.md запиши таблицу «пояс / наш σ / эталон σ / разница %» (мембранные, эквивалентные, фибровые), допустимый налив, перемещения. Где расхождение больше 10 %, найди причину.
```

## Пояс 12 и стык «стенка–крыша»
```
В Т-001 пояс 12 даёт 220 МПа (мембранные), в эталоне 16,7. Найди причину: нагрузка крыши, связь RBE3 конца балки, опорная полоса, сетка у кромки. Проверь сходимость по сетке 200/100/50 мм у кромки и сравни со схемой передачи нагрузки в эталоне. Исправь модель узла и покажи таблицу до/после на Т-001 и РВС-10000.
```

## Нелинейная устойчивость (эталонная схема)
```
Нелинейная устойчивость стенки пустого резервуара по методике из ANSYS_Stability.pdf: Large Displacement Static, автоматический шаг (подшагов 20, мин. 20, макс. 1000), малая возмущающая нагрузка (около 0,05 % от ветровой на 2/3 высоты по ветру), ветер в двух направлениях (Y и Z), нагрузка «вакуум + снег + ветер». График «перемещение узла стенки от множителя нагрузки», критическая нагрузка там, где перемещение резко растёт. Сравни с линейным k стенки. Результат в tools/diag/nonlinear_buckling.md.
```

## Скорость прогона
```
Замерь время по этапам (timing.log), найди 3 самых долгих этапа, предложи и реализуй безопасные ускорения, покажи выигрыш в минутах. Результат в tools/diag/timing.md.
```

## Работа над сайтом (облачная сессия)
```
В студии (server/templates/studio.html, server/static/studio.js) сделай: <описание>. Проверь в Chromium (playwright), прогони python -m pytest tests -q, закоммить и запушь в claude/ansys-report-automation-8asxtm.
```

## Правила
- Облачная и локальная сессии не правят одну ветку одновременно: локальная пушит в `local/ansys-debug`, облачная её сливает.
- Результаты прогонов: ветка `diag-logs` (`diag/diag.txt`, `diag/report.docx`, `report_30000.docx`).
